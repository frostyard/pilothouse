# Security Policy

## Supported versions

Only the latest release gets fixes. A release is a tag named `vX.Y.Z` on
https://github.com/frostyard/pilothouse/releases.

The rolling `dev` prerelease and every older release get no fixes. Upgrade to
the latest release before you report a vulnerability that an older release
shows.

## Reporting a vulnerability

Use GitHub private vulnerability reporting:
https://github.com/frostyard/pilothouse/security

Open the Security tab and click **Report a vulnerability**.

Do not open a public issue with the details of a vulnerability. Do not post
credentials in an issue, a pull request or a discussion.

## What to include

- The affected commit.
- The impact: what an attacker can do.
- The steps to reproduce it.
